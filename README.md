# Launch Dashboard

Upcoming rocket-launch schedule dashboard.

## How to use

Double-click **`index.html`** (or drag it into Chrome or Safari). Nothing to install.
It pulls upcoming launches live from The Space Devs (Launch Library 2), so it needs internet.
What you enter is saved in that browser on this computer, not in this repo, so it won't sync between devices.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
